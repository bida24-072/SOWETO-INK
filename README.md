# Soweto Ink — Official Website

A multi-page website for Soweto Ink, a premium tattoo and piercing studio with roots in Soweto and a location in Gaborone, Botswana.

## Project Structure
- **`index.html`** — Homepage with a cinematic video hero section.
- **`services.html`** — Details the core services: Tattoos, Piercings, and Jewelry.
- **`about.html`** — Brand story and expansion to Botswana.
- **`contact.html`** — Booking and inquiry form.
- **`css/style.css`** — Shared design system (dark theme, bold typography).
- **`README.md`** — This file.

## Running Locally
This is a static site. Simply open `index.html` in your browser. For a better development experience (live reloads), you can use a local server:
```bash
# If you have Python installed:
python -m http.server 8000
# Then visit http://localhost:8000
